# LightSenRefGLEAN

For 20m bands training we utilise dataloader in two modes:
* Degraded Venus + Original Venus image pairs
* Sentinel + Venus image pairs

Here for the first mode we have the B2, B3, B4, B8 bands at 5m resolution from venus data, but for second mode we would need to enhance the 10m images from sentinel in dataset and store it in dataset folder.
